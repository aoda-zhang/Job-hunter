# 运行摘要邮件模板

本文档是 `email-notify` skill 的**唯一邮件内容基准**。发送前必须先读本文档；不得自行增加字段、改成职位列表或附带详细数据。

## 原则

- 只发摘要，不发职位明细。
- 不写公司名、职位名、URL、JD 原文、匹配分数或推荐意见。
- 正文用中文，主题保持 ASCII。
- 每封邮件不超过 20 行。
- **区分「当日累计」和「本次新增」**：日报是当天累积快照，本次运行可能只打开少量新职位。
- 所有数字来自当天的日报汇总表和最新审计条目；无法确认时写「无法统计」，不得估算。

## 主题

```text
[Job Hunter] YYYY-MM-DD <status> · <matched> matched
```

- `<status>`：`ok` / `partial` / `failed`
- `<matched>` 是**当日累计命中数**（日报汇总表的「命中」），不是本次新增数
- 没有数字时写 `no data`
- 示例：`[Job Hunter] 2026-11-10 ok · 28 matched`

## 正文

```text
Job Hunter 每日检索摘要

日期：2026-11-10
检索时间：14:05 – 14:14（9 分钟）
检索范围：德国（全国）
当日累计：检查 135 · 可投递 28 · 复核 12 · 排除 95
本次新增：检查 5 · 可投递 0 · 排除 5
已投递跳过：0
停止原因：无更多结果页（127 张卡片已翻完）
日报：reports/daily/2026-11-10.md

状态：正常完成
```

字段来源与规则：

| 行 | 来源 | 规则 |
|---|---|---|
| 日期 | 审计 `runAt` | `YYYY-MM-DD` |
| 检索时间 | 审计 `runAt` / `finishedAt` / `durationSeconds` | `HH:MM – HH:MM（N 分钟）`；缺结束时间只写开始时间；缺时长省略括号 |
| 检索范围 | 审计 `scope.countries` / `scope.locations` | 无 `locations` 写「（全国）」；有则列城市，最多 5 个，其余用「等」 |
| 当日累计 | 日报「运行汇总」表 | 检查=`成功读取 JD`，可投递=`命中`，复核=`需人工复核`，排除=`确认不符（已排除）` |
| 本次新增 | 审计 | `postingsInspected` / `matched` / `excluded` |
| 已投递跳过 | 审计 `appliedSkipped` | 没有则写 0 |
| 停止原因 | 审计 `stopReason` | 翻成一句中文；未记录时写「未记录」 |
| 日报 | 固定路径 | `reports/daily/YYYY-MM-DD.md` |
| 状态 | 运行完成情况 | 见下表 |

如果日报汇总表缺失或无法读取，只写「本次新增」那一行，并省略「当日累计」。

## 状态写法

| 情况 | 状态 |
|---|---|
| 日报已写入，翻页到结束或已覆盖 `lookbackHours` | `正常完成` |
| 结果没翻完、部分页面无法读取、筛选无法应用 | `部分完成：<一句原因>` |
| 登录、验证码、浏览器不可用、未写入日报 | `失败：<一句原因>` |

**复用当天早前已判定的职位、本次只打开少量新职位，属于正常完成，不是部分完成。** 只有覆盖不完整才算 `partial`。

主题里的 `<status>` 对应 `ok` / `partial` / `failed`。

## 禁止内容

- 职位列表、公司名、职位名、链接、薪资、JD 片段
- 匹配分数、推荐等级、候选人评价
- SMTP 密码、Cookie、会话令牌、浏览器数据
- 超过 20 行的日志或错误堆栈

## 失败邮件

无法生成完整统计时，只发：

```text
Job Hunter 运行失败

日期：2026-11-10
失败阶段：搜索 / 读取 JD / 写报告
原因：<一句话>
已保留：reports/daily/2026-11-10.md（若已写入）

状态：失败
```
