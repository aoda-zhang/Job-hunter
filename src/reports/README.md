# Reports

Reports should group vacancies into:
- **Matched** — job title, JD language and technical keywords all match.
- **Review** — one or more filter dimensions could not be evaluated.
- **Not matched** — at least one dimension is a confirmed mismatch.

For every vacancy include the source URL, discovery timestamp, country, detected JD language, matched title variant, matched technical keywords, per-dimension statuses and concise reasons. Do not display or sort by a candidate-fit score.
