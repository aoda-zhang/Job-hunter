# Roadmap

## Local OpenCode workflow

- [x] Single root configuration: `job-hunter.config.json`
- [x] Define exactly three vacancy filters: title, JD language and technical keywords
- [x] Define local browser-based discovery workflow in the OpenCode skill
- [x] Save one Markdown report per local calendar date
- [x] Keep unknown or incomplete vacancies for manual review
- [x] Keep company research separate from daily job discovery
- [x] Define manual Phase 2 company and role research skill
- [ ] Verify browser automation with the user's locally configured OpenCode browser tools
- [ ] Refine source search behavior based on real local runs

## Explicit non-goals

- No CI pipeline or cloud deployment.
- No mandatory database or hosted backend.
- No complex source-adapter framework.
- No candidate-fit score, weighted ranking or additional rejection criteria.
- No automatic applications, employer messages or account creation.
